# V0.9.4 电源保护修复验收清单

## 目标

修复启动保护把旧备份误当成当前已生效的问题、电源设置部分失败后没有回滚的问题，以及睡眠告警重复打扰和缺少直接处理入口的问题。

## TODO 与结果

- [x] 有旧备份时仍读取当前活动电源计划并验证超时；发现设置重新开启后重新关闭。
- [x] 电源计划切换后保存新计划原值，保持原计划和用户当前选择可恢复。
- [x] 电源设置只在读取成功后保存原值；执行失败时回滚本轮已修改项。
- [x] 回滚失败或日志更新失败时保留恢复记录，不丢失恢复依据。
- [x] 增加“同一条就绪告警只提醒一次”的去重；告警改变或清除后重新允许提醒。
- [x] 在线守护页增加“一键关闭睡眠/休眠”按钮，执行后自动复查并反馈结果；保留打开 Windows 电源设置的入口。
- [x] 通知点击直接执行可逆电源保护，不再只打开设置页。
- [x] 版本号、安装脚本与下载说明更新至 `0.9.4`。
- [x] 全量 Windows Release 工作流成功并核对全部发布资产。

## 能力边界

电源保护只能降低电脑因睡眠/休眠而离线的风险，不能保证校园网设备、路由器、供电、Windows、硬件或 UU 服务永远可用。
