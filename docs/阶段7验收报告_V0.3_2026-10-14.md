## 0. 范围界定说明

现行执行计划对 P7 只有 §0.2 的行级定义：

> **P7 远程保障与远程重连验证**：远控探测、敏感期延迟切回、崩溃恢复；
> **是（受控、真实远控会话）**；前置依赖 P5。

该行对应开发方案 §12-P4「远程保障」的五项任务：

1. 远程控制软件连通性检查；
2. 远程会话敏感期的安全切回策略；
3. 后台监控崩溃恢复；
4. Windows 启动及恢复运行验证；
5. Wi-Fi、路由、Portal 与远程控制日志关联。

出口条件为「**远程访问能够在实际故障切换后重新建立**」。该条件必须依赖**真实远控会话**
才能验证，属 P8 全量受控验收范围，需用户显式授权后执行（见 §8），本阶段不以任何
Mock 结果冒充此项通过。

本阶段另叠加方案 §4.3 / §7.2 / §7.3 / §11 四处约束确定范围：

| # | 约束 | 落地口径 |
|---|---|---|
| 1 | §4.3 远程会话延迟 | 会话进行中推迟自动切回；但**不得永久阻止切回**（上限后放行并告警）；会话结束后经静默窗口防抖 |
| 2 | §7.2 独立恢复线程 | 看门狗独立于监测线程；发现线程死亡 + 未完成路由事务时**先崩溃恢复、再重启监测** |
| 3 | §7.3 远控现实能力边界 | 远控客户端无人值守/断线自动重连**无法程序化验证**，只作人工项上报，不假扮「已通过」 |
| 4 | §11 托盘字段 | 「远程保障」字段在既有三态之外新增「远程会话敏感期：推迟切回」，并展示远控详情与无人值守缺口 |

### 0.1 关键取舍（AGENTS §2.5 Question 机制）

P7 存在两处文档无法唯一确定、且直接关系"远程在线"安全的取舍，已按 §2.5 向用户确认：

| 决策项 | 用户选择 | 落地 |
|---|---|---|
| 敏感期判据 | **仅 `Established` TCP 连接**（推荐） | 仅监听 / 仅 UDP 不算会话进行中；否则 Tailscale（`tailscaled`，TCP 443 监听 + UDP 41641）常驻会导致**永不切回**，与 §4.3「有线恢复优先」冲突 |
| CLI 与托盘的切回门禁默认值 | **CLI 默认不接入，托盘默认开启** | `route --defer-failback` 为显式 opt-in（受控命令行不擅自改变 P5 行为）；托盘配置 `remote_defer_failback` 默认 `True`（无人值守场景默认保护） |

**不越界声明**：P7 不改动认证引擎（`campus_core.repair_service`）、不改动 P3 状态机默认行为
（`failback_gate=None` 时逐分支等价）、不执行真实路由切换与真实远控会话故障演练（P8）、
不把 V0.3 设为长期无人值守默认模式（P8 出口条件）。`campus_remote.RemoteSafetyGuard`
本身**没有任何副作用能力**：不写路由、不认证、不触碰 Clash、不杀进程、不关网卡。

## 5. 实现与文档对照

| 方案条目 | 实现 | 说明 |
|---|---|---|
| §4.3 会话中延迟切回 | `RemoteSafetyGuard.failback_gate()` | 推迟原因含「已推迟 x/y 秒」，可读可审计 |
| §4.3 不得永久阻止 | `max_defer_seconds`（默认 1800s） | 达上限放行并明示「会话可能瞬断」；安全阀优先于便利 |
| §4.3 防抖 | `quiet_seconds`（默认 60s） | 会话结束后静默窗口内继续推迟，避免「刚切回又被连入」 |
| §7.2 独立恢复线程 | `MonitorWatchdog`（纯逻辑 + 显式 `now`） | 与监测线程解耦；四类动作 `OK` / `RESUME_RECHECK` / `RESTART_MONITOR` / `MANUAL_REQUIRED` |
| §7.2 崩溃恢复顺序 | `apply_watchdog_decision()` | **先恢复路由、再重启监测**；恢复失败记入 `errors` 但不阻塞重启 |
| §7.2 未完成事务探测 | `pending_transaction` 惰性回调 | 仅在实际需要重启时才调用（U-7-17 用 `pytest.fail` 守卫证明新鲜心跳下零 I/O） |
| §7.3 能力边界 | `RemoteReadinessItem(severity="manual")` | 人工项**不参与** `ReadinessReport.ok` 判定，无法程序化验证的不假扮通过 |
| §11 托盘字段 | `FailoverStatus.remote_guard/detail/warnings` | 新增 `REMOTE_SENSITIVE`；P6 四态常量与「只读监测」标签**保持原名** |
| 凭据脱敏（AGENTS §6） | `RemoteEventLog` + `credentials_present` 仅存在性 | 日志只含 `kind/detail/correlation_id/at`；禁词表断言覆盖 |

模块边界：`campus_remote` 不 import tkinter / pystray / winreg / requests；路由变更只经
P5 `RouteGuard`；认证引擎零改动；真实 I/O 全部收敛到 `build_windows_remote_ops` 一个适配层。
