# V0.7.0 界面重设计与发布

用户已要求完成设计、实现和新版 Release。用户追加要求：普通用户不接触代理术语，启动后自动验证和修复。实施包含后台准备协调器与在线守护接线；开发与验收不操作本机正在运行的助手、代理、UU 或网络。

## 设计与验收

参考用户提供的 Magpie：左侧导航、紧凑标题、浅灰底、白色内容面板、紫色主按钮，全文 Microsoft YaHei UI。颜色：背景 #F6F6F8、侧栏 #EEEEF2、面板 #FFFFFF、正文 #25252D、次要文字 #666673、主色 #6554C0。正常/异常只使用少量状态色，不大面积铺色。

布局：左侧固定导航；右侧页面顶部为标题/说明，概览显示真实网络状态、两条链路与 UU 状态、主要操作；网络详情、恢复步骤、活动记录各自成页。代理检查窗口统一字号和 DPI 缩放，提供结果摘要、明确的下一步和可展开的详细报告。健康且无已知缺项时首次启动不弹确认框。未知状态不得显示“已验证”。

对照需求复核：保留 Magpie 的桌面工具布局，不采用营销大标题/虚构百分比/自动闪烁；代理持久规则缺失与当前是否联网分开解释，修复仍使用既有备份事务；用户本轮明确要求自动处理，标准启动不再要求用户点击修复或退出 Clash。高级诊断保留手动撤销与进一步排查入口。

## 后台自动处理（用户本轮追加）

- 安装包首次运行默认开启在线守护与登录后自启；升级保留既有开关，主界面用一个“开启在线守护”按钮启用。强制重启电脑不擅自开启，沿用已保存的用户授权。
- 自动补齐系统校园地址绕过；唯一识别的 Clash Verge 配置缺项时，记录原客户端位置、停止已核对 PID 的客户端、备份并追加持久规则，再从原路径恢复客户端。不同机器各自读取端口、模式和配置。服务与 UU 不在此进程停止范围内。
- 客户端恢复记录先于停止写盘，助手中断后下次启动补做恢复。修改事务失败回滚，客户端在 finally 中恢复；后续用户改动不会被强行覆盖。
- 与重连/三层恢复互斥，每五分钟核对配置。直连正常且代理请求连续三次失败时才恢复客户端，至少间隔五分钟；不猜测代理端口。代理失败不能继续显示正常。
- 未安装 UU 时仅守护网络，避免反复启动不存在的软件；状态不可确认时保留未知。普通页面只显示连接、在线守护、账号、开机运行和更新；技术配置在高级选项中。
- 多个配置目录、未知客户端/PAC、权限或配置冲突时保留现状和基础保护，记录诊断；不假称所有 VPN/TUN 已支持。完全死机时本机程序无法执行恢复。
