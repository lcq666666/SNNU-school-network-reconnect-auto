## 完成内容

1. 新增 `campus_transport.InterfaceTransport`：
   - 每个 TCP/UDP socket 设置 `IP_UNICAST_IF` 并回读校验。
   - 校验源 IPv4、接口索引和显式 IPv4 DNS 服务器。
   - 约束失败、回读不一致、连接失败均 fail-closed，不回退系统解析器或未绑定连接。
   - DNS 使用指定 DNS 服务器的接口受限 UDP 查询，校验 transaction ID、QR、RCODE、问题名、压缩指针和 A 记录边界。
   - HTTP/HTTPS 使用 `trust_env=False`、禁止自动重定向、限制响应体 512 字节；HTTPS 保留 urllib3 TLS 校验路径，不设置 `verify=False`；显式代理被拒绝。

2. 修改 `campus_network.py`：
   - `InterfaceHealthChecker` 只消费 `engine.for_interface()` 提供的受限传输。
   - 系统最佳路由不再冒充指定接口出口证明。
   - 未能建立接口约束时直接返回 `PROBE_UNRELIABLE`，不发 TCP/HTTP/DNS 探测。
   - DNS 按接口读取，不使用全局 `getaddrinfo`。
   - 网关 TCP 端口关闭只记录诊断证据，不单独判定网关不可达。
   - 增加明文 HTTP Portal 识别点，同时保留 HTTPS 探测。

3. 修改 `tools/netdiag.py`：
   - 只读采集 `Get-DnsClientServerAddress -AddressFamily IPv4`。
   - 将 DNS 服务器按 `ifIndex` 纳入 `DiagReport` 和 JSON 契约。

4. 修改 `campus_snnu.py` / `campus_reconnect.py`：
   - SNNU 认证必须经过显式 `bind_interface` 受限会话。
   - 仅源地址绑定或仅 Find-NetRoute 证明不再允许继续请求。
   - 无受限会话时返回 `E_SNNU_AUTH_PATH_UNCONFIRMED`，不发送凭据。
   - 生产 CLI 使用 `InterfaceTransport` 建立会话约束。
