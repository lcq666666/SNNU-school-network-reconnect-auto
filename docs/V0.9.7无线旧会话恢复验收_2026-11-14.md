# V0.9.7 无线旧会话恢复

用户已明确授权把本次成功的无线会话断开与重新登录流程加入自动守护。

- [x] 有线健康时持续维护无线，UU 采集失败也不跳过备用维护。
- [x] 连续三轮无线异常，普通认证成功但公网仍失败后，才进入会话重建检查。
- [x] 重建前确认新鲜可信快照、目标无线网卡、源地址和 SNNU 关联状态，有线执行接口受限公网验证。
- [x] 校园状态页账号和当前 IP，以及设备明细同一行的 IP/MAC 全部匹配本机无线身份。
- [x] 所有会话请求绑定无线接口并关闭环境代理，注销不跟随重定向。
- [x] 重建前持久化限频记录，每 6 小时最多一次。磁盘写入失败、记录损坏、暂停或身份不匹配时不执行注销。
- [x] 注销响应丢失也尝试重新登录，沿用凭据管理器、验证码 OCR 和公网复核。
- [x] 设置页提供明确授权选项，通用默认关闭，保留升级前配置。
- [x] 全量 1520 项，1519 通过、1 项平台跳过，零失败。ruff 与 diff 检查通过。

本次真实恢复在用户授权后经 WLAN 执行，注销后无线状态由 ONLINE 变为 AUTH_REQUIRED，有线 HTTP 仍为 200。随后使用本机保存的账号与移动运营商配置重新登录，动态解析认证端口后无线恢复。两次独立复核均得到有线和无线各四站验证通过。本次没有出现验证码。

新增自动流程通过离线集成测试验证，没有为测试再次注销已恢复的无线会话。持续双链路可用性及真实有线故障后的接管尚需长期真机观察。
