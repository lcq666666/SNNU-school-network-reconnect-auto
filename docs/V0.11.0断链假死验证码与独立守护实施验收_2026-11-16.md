# V0.11.0 断链、假死、验证码与独立守护实施验收

## 已实现

- 恢复控制器支持独立策略预算：连续故障确认、首层 Wi-Fi 修复、Portal 认证冷却、UU 外连确认均可配置；生产默认值为 10 秒探测、3 次确认、300 秒认证冷却。
- Portal 图形验证码继续使用同一 HTTP 会话，增加四位数字严格校验、多路图片预处理和结果一致性判断；最多三次挑战，无法确认时不提交猜测。
- 新安装启动时默认开启 UU 用户态自动恢复；升级已有配置时保留用户原有开关值。
- 增加 `--guard` 独立守护入口、心跳文件和 Windows per-user Task Scheduler 注册/清理；守护仅拉起主程序，不读取凭据、不执行网络认证。
- 托盘仪表盘显示独立任务计划守护状态；用户主动退出写入停止心跳，守护不会立即重新拉起。
