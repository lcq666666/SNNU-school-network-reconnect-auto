# V0.9.0 全自动持续在线与界面重构验收报告

## 范围

本阶段在 `fix/observer-degraded-20261112` 分支完成。目标是把启动检查、可逆的 Windows 设置、三层恢复、Wi-Fi 独立验证、就绪展示、响应式桌面窗口和标准安装包连接成一个可验收闭环。

## 已实现

- 就绪报告区分“已通过、需要处理、正在检查、无法自动确认”，人工确认项不再计入自动缺口。
- 启动入口在打包版每次运行时自动开启在线守护、助手登录后自启和三层恢复开关；电源计划关闭睡眠/休眠超时前保存旧值到 `power-guard-backup.json`，不读取或记录 Windows 密码。
- 三层恢复第一层只重连 SNNU Wi-Fi；第二层才保存/关闭/恢复系统代理并执行校园认证；第三层保留 15 分钟、60 秒倒计时、6 小时冷却、恢复记录和取消倒计时门禁。
- 完整远控自检增加 UU 外部 TCP/UDP 连接项；电源计划通过只读 `powercfg /query` 读取实际 AC/DC 超时，避免“支持睡眠”被误报为缺口。
- 主窗口使用自绘标题栏，Windows 下恢复 Alt-Tab 样式；窗口按 DPI 和工作区计算尺寸，主题实时重绘。
- 新增 Inno Setup 配方、构建脚本和 release 资产：安装包、便携版、各自 SHA256、`build_info.json`。
- 应用内更新在安装目录下载并启动安装包，便携目录继续使用单文件启动预检和回滚。

## 验收命令

```text
.venv\Scripts\python.exe -c "import gc; gc.disable(); import pytest, sys; sys.exit(pytest.main(['-q','-ra']))"
.venv\Scripts\ruff.exe check .
git diff --check
```

测试只使用模拟注册表、电源命令、网络、进程和时间；不执行真实断网、校园网认证、UU 清退或 Windows 重启。Windows release runner 另执行 PyInstaller 启动自检和 Inno Setup 构建。

## 现实边界

“永远在线”仅表示在电脑有电、Windows 正常运行、校园网和 UU 服务可用时持续执行有界恢复。断电、硬件故障、校园网设备数限制、UU 服务端故障和用户尚未完成的 Windows 自动登录/UU 无人值守确认，仍需要人工处理。
