## 1. 范围与实现

| 出口条件 | 结论 | 实现与测试证据 |
|---|---|---|
| 超时旧任务不得覆盖新任务状态 | PASS | `TraySnapshotSource` 任务 ID 匹配；旧任务只释放在途额度、登记丢弃，不覆盖快照/错误/活跃任务状态；U-75-1A-01/02/03 |
| 起始时刻 0.0 可正确超时 | PASS | 显式判断 None；U-75-1A-04 |
| 任务数量有上限且可恢复 | PASS | 默认最多 3 个在途采集；连续超时达到上限后拒绝重试，旧任务退出释放额度；U-75-1A-05 |
| 无下一次请求时，迟到结果也不得发布 | PASS | `_run()` 完成时检查采集耗时并作废代次；`test_late_completion_without_retry_is_not_published` |
| 同步入口不能绕过单飞、在途计数及限流 | PASS | `collect_now()` 锁内准入、计数、更新请求时刻；同步→同步、同步→异步、异步→同步三种限流回归 |
| 拒绝执行不消耗动作冷却 | PASS | `RefusingExecutor` 返回 gate_passed=True / attempted=False / executed=False；U-75-1A-06/07，分别真正触发 Metric、Portal、Wi-Fi 重连拒绝，再恢复可信验证可执行 |
| AUTO 要求完整三轴及可定位的不同接口 | PASS | 两轴 ifIndex 必须是非 bool 的正整数且不超过 UINT32，两者不得相同；结构纯函数测试及 `TrayApp._failover_tick()` 四场景闭环（有效、缺轴、非法索引、重复索引） |
| 观测参数可配置且有限幅 | PASS | max_age 默认8s/范围1–30s，timeout默认12s/范围3–60s，interval默认3s/范围1–30s；非法类型回退默认，4组参数回归 |
