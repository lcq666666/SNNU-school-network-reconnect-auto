## 2. 行为变化 / 迁移

- **`once` 与托盘/watch 共用单实例互斥体**：托盘或 watch 在运行时，`once`（含 `--force`）会被拒绝并退出（码 1）。
  手动联调请先退出托盘；`once --dry-run` 不认证，不受限制。
- **SSID 改为完整匹配**：Wi-Fi 名称必须与系统显示的 SSID 完全一致（含大小写与空格）。
- **端口解析失败不再回退 8601**：改为如实报告不可达，不提交凭据。
- **配置位置**：源码模式默认 `%LOCALAPPDATA%\CampusReconnect\tray_config.json`；
  打包（便携）模式为 exe 同级。旧位置 `脚本目录/tray_config.json` 仅**只读回退**，不移动、不删除。
- **系统代理联动**：仅在授权且端点验证通过后写入；默认不启用。

## 3. 已知限制

- 仅适配**陕西师范大学** snnuportal；改 SSID 不会自动适配其他学校。
- 仅支持 Windows 10/11 **x64**（依赖 winreg/ctypes/tkinter）。
- 学校 Portal 为明文 HTTP，认证报文本身不加密（学校系统固有限制）。
- 仅写注册表**不保证**所有应用 / Clash 界面立即采用新代理设置。
- 重建产物不保证 bit-for-bit 复现（时间戳 / UPX 等）；只保证按锁定依赖可重建并通过测试。
- 是否影响同账号其他设备取决于学校并发策略，本工具不作绝对保证。
