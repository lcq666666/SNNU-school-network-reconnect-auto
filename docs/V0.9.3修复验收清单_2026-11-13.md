# V0.9.3 修复审查与验收清单

## 目标

修复在线保护告警无法跳转、手动重启 UU 时界面等待，以及本轮代码审查识别出的回归风险；保留原有 fail-closed 网络验证。版本升级为 `0.9.3`。

## 待办与结果

- [x] 将手动 UU 重启确认移出 Tk 回调线程，避免 UI 在等待确认期间卡住；同一时刻只允许一个确认流程。

## 发布边界

本清单不宣称任何机器可“永远在线”。断电、Windows/硬件故障、校园网或 UU 服务故障以及学校设备数限制无法由客户端软件消除。只有 Release 工作流成功并核对资产后，`v0.9.3` 才算发布完成。
