# V0.10.4 断链恢复与 UU 在线保障验收

## 修复内容

- 图形验证码图片或 OCR 临时失败时，在同一 Portal 会话刷新登录页和验证码，最多按既有限额重试；失败不提交猜测值，日志不记录验证码、密码或 Cookie。
- `powercfg /query` 的中文标签现在可以解析，在线守护不再因本地化输出无法识别而跳过防睡眠配置。
- UU 启动命令执行后，如果用户态仍没有外部连接，恢复控制器会在确认窗口结束后重新进入 UU 恢复门，并继续服从冷却和网络验证条件。
- 新增 PRD：`docs/PRD校园网断链自动恢复与UU在线保障.md`，明确校园网断链、Portal 认证、四位验证码、移动运营商和 UU 假死的验收流程。

## 验证

- 全量离线测试：`1120 passed, 1 skipped`。
- `ruff check`：通过。
- `git diff --check`：通过。
- 重点回归：验证码同会话重试、认证状态页账号匹配、UU 用户态恢复、UU 恢复重试、中文电源计划解析、网络未恢复时不重启 UU。

## 边界

- 校园网账号的并发设备限制由服务器控制，助手不能保证两台设备同时在线，也不能替账号解除挤下线。
- 本机只能验证 UU 用户态进程和外部 TCP；远端控制端实际会话仍需 UU 服务端确认。
- 监测器自身崩溃后的独立 Windows 服务/任务恢复、真实断电/死机恢复和真实校园网验证码现场验收仍属于部署环境验收项。
