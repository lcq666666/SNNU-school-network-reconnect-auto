# V0.8.2 更新启动预检与托盘点击修复

## 修复内容

- 更新安装前先运行暂存 EXE 的无界面加载自检；只有 Python 运行库与应用模块加载成功，更新器才退出旧版本并替换程序。自检失败时保留当前版本，并在更新窗口报告失败。
- 安装脚本交接后再校验一次暂存 EXE，避免交接期间文件异常时替换已安装程序。
- 将“打开主界面”设为托盘默认动作，支持点击托盘图标打开主界面。

## 诊断与验证

- v0.8.1 官方 EXE 下载大小及 SHA256 与 Release 校验文件一致；在当前开发机上 `--startup-check` 返回 `ok`。
- v0.8.1 EXE 内含 `python312.dll`、MSVC 与 UCRT 运行库。截图中的 `LoadLibrary: 找不到指定的模块` 在当前开发机未复现，现有证据不能判定目标电脑上具体缺失或被拦截的依赖。
- 新增离线回归覆盖托盘默认点击、更新启动预检成功/失败和无界面加载检查。
- 未读取校园网凭据，未执行网络恢复或修改 Clash/系统代理。
