# V0.8.1 观测器恢复与 Wi‑Fi 独立验证

本版本修复校园网断开后长时间不恢复的问题，并把人工操作压缩到必要的登录动作。

## 用户可见变化

- 以太网断开时仍单独检查 SNNU Wi‑Fi，不再因有线状态缺失而跳过无线验证。
- 三轴采集任务超时或迟到时会记录原因、淘汰旧任务并在有界条件下重建采集窗口，避免一直停在“正在读取网络信息”。
- 手动验证缺少接口事实时先刷新一次；仍无法确认时明确提示原因，不猜测接口、不用以太网替代 Wi‑Fi。
- 校园网账号、密码或验证码认证失败时提示打开校园网登录页；只在符合人工处理条件且启用了 Edge 兜底时自动打开独立登录页。
- 代理探测失败不会自动停止或拉起 Clash Verge，因此不会突然弹出 Clash 窗口，也不会改写用户当前代理配置。
- 深浅色主题切换立即刷新主窗口、页面和滚动条，无需重启。
- 更新下载继续使用应用内进度窗口、SHA256 校验和安装后自动重启，并在更新前保存现有配置。
