# V0.10.1 安装启动失败修复验收

## 问题与处理

另一台 Windows 电脑安装更新后，启动器报 `Failed to load Python DLL`，路径指向 `%TEMP%\_MEI...\python312.dll`。Windows 加载器的“找不到指定的模块”也可能由传递依赖导致；目标电脑尚无启动日志或系统信息，不能据此确认缺少哪一个 DLL。

安装版原来也是 PyInstaller 单文件程序，启动时把 Python 和应用运行库释放到临时 `_MEI` 目录。V0.10.1 将安装版改为 PyInstaller 目录包：主程序和 `_internal` 运行库一起安装在 `%LOCALAPPDATA%\Programs\CampusReconnect`，绕过临时解压加载路径。单文件便携版继续提供。安装器限定 Windows 10/11；Windows Release 构建分别启动自检单文件版与目录版。

## 边界

目录式安装避免从临时目录装载打包 DLL，降低临时目录策略、杀毒软件隔离和解压异常影响启动的机会，但目前不能证明目标电脑故障具体由这些因素中的哪一项造成。只有在目标电脑安装 V0.10.1 并验证启动后，才能确认该现场问题是否解决。若目录式版本仍无法启动，应收集 Windows 版本、安装目录文件清单、安全软件隔离记录和对应事件日志继续诊断。
