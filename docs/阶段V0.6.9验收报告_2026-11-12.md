## P2 发布验收

本机最终完整离线回归：**1236 passed, 1 skipped，28.06 秒**；证据 `build/v069-final-tests.xml` 和 `.log`。`ruff check .` 与 `git diff --check` 通过。

回归过程中修复一项旧 UI 测试的隔离缺陷：下载测试替换全局 `threading.Thread` 会污染标准线程池。现只替换被测模块的线程工厂，并以独立线程池完成任务作为回归断言。相关 UI 假件在构造时直接传入默认配置，不读取本机运行配置。未通过删断言或跳过用例消除失败。

GitHub CI、发布构建与资产摘要结果将在通过后记录。

## 真机验收边界

本次没有对用户正在运行的代理做故障注入。其他设备需在本机检查并确认持久修复，重新启动其代理客户端后再次检查。当前生成文件含规则只代表配置证据，实际认证页连通与 UU 控制端连接需单独验证。未识别的客户端/PAC/其他 VPN 会提示处理路径，不能承诺所有第三方组合都自动配置成功。
